# Context proiect PRIMUL

## Ce este
Proiect web local, dezvoltat pe XAMPP, stack PHP + MySQL + HTML/CSS/JS.

## Stare curenta
Proiect abia initializat (16 iulie 2026) - structura de foldere creata, fara functionalitati implementate inca.

## Decizii de arhitectura
- Fara framework PHP la inceput (Composer/Laravel/Symfony) - se adauga doar daca userul cere explicit.
- Frontend simplu (HTML/CSS/JS), fara build step, pana cand nevoia de complexitate justifica un framework JS.
